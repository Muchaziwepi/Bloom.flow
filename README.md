# bloom.flow

> Make room for deep work.

bloom.flow is an aesthetic focus workspace designed to make concentrated work feel calm, intentional, and personal. It combines an unlimited focus timer with a second-by-second digital clock, vibrant visual themes, custom backgrounds, productivity tools, and a distraction-free full-screen experience.

## Features

- Unlimited focus sessions from 15 minutes to 999 hours
- Live digital clock with seconds
- Short and long break controls
- Custom background image upload
- Vibrant visual themes
- Compact productivity dock for quick access
- Timed to-do list with completion tracking
- Minimal notes pad for ideas and intentions
- Music options for Spotify, Apple Music, and ambient sound
- Language selector with English, Spanish, French, Japanese, German, Portuguese, Italian, and Korean
- Full-screen focus mode
- Floating timer window option for keeping time visible while working elsewhere
- Responsive interface for desktop and smaller screens

## About

bloom.flow is built for people who want a more beautiful way to focus. Instead of treating productivity as a rigid checklist, the workspace creates a personal atmosphere around each session: choose a theme, set your own pace, add a background, organize your tasks, and settle into deep work.

## Tech stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide icons
- Vercel Analytics
- Vercel Blob integration prepared for user backgrounds
- Neon integration prepared for future saved preferences and authentication

## Getting started

Install dependencies and run the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Project structure

```text
app/
  page.tsx       Main bloom.flow workspace
  globals.css    Visual theme and responsive styles
  layout.tsx     Metadata and app shell
public/          Static icons and assets
```
